關於這個網站

這是一個標準的網頁佈局範例。包含了最基礎且最重要的四個部分：標頭 (Header) 用於展示網站名稱與主旨、導覽列 (Navbar) 提供使用者切換頁面的連結、主要內容區塊 (Main) 用於放置文章與資訊，以及頁尾 (Footer) 放置版權聲明與其他補充連結。

透過 Tailwind CSS，我們不需要手寫冗長的 CSS 檔案，只需在 HTML 標籤中加入類別 (Class) 名稱，就能輕鬆完成排版、顏色設定與響應式設計（RWD）。

響應式設計 (RWD)

您可以嘗試縮放瀏覽器視窗，或是使用手機檢視此頁面。您會發現導覽列與內容區塊都會自動適應螢幕寬度，保持良好的閱讀體驗。

簡潔乾淨的排版

運用留白 (Padding/Margin)、圓角 (Border-radius) 與微小的陰影 (Shadow)，能讓整個網頁看起來更加現代、有質感且易於閱讀。
